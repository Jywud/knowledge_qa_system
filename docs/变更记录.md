# 变更记录

## 2026-11-11：P1 缺陷修复与密码重置流程完善

### 文件更新保护

- 更新文件先保存到 `uploads/.pending/`，处理成功后才提交新分块和文件元数据，版本号随成功提交递增。
- 超限、解析失败、向量化失败、空内容、向量数量不匹配或提交失败时，保留原文件、原分块和原版本。
- 新版本原文件存放在 `uploads/.versions/`，与旧上传路径隔离，避免文件名碰撞；重建和删除兼容新旧布局。
- 提交结果不明确时重新核实数据库状态，避免误删已提交的新文件；请求阶段用版本、状态和 `updated_at` 确认归属，防止恢复时覆盖另一请求。
- 更新失败且原版本仍可用时，恢复可用状态并在文件列表显示失败原因；后台成功前不提前提示版本已升级。

### 删除关联数据保护

- 知识库有关联会话或文件正在处理时，返回中文 `409` 提示并保留数据。
- 用户有关联知识库、上传文件、会话或审计记录时，返回中文 `409`，避免直接删除产生外键冲突。
- 捕获删除时的外键冲突并回滚；知识库删除与审计在同一事务提交，成功后清理对应原文件。

### 密码与登录令牌

- JWT 增加由当前密码哈希和现有 JWT 密钥计算的 HMAC 密码版本，个人改密或管理员重置后，旧令牌立即失效。
- 拒绝缺少密码版本及格式异常的令牌，统一返回 `401`。
- 个人改密及管理员在用户管理页重置自己密码后，清理本地凭证并跳转登录；重置其他用户密码时保留当前登录。
- 用户管理表格兼容用户状态为空，避免清理凭证后的渲染异常。
