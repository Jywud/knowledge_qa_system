# 角色与知识库访问权限设计

状态：已按用户确认的全新系统方案实现；不兼容旧角色接口与旧对话。

## 产品规则

- 员工通过角色获得知识库权限，不再保留固定“普通用户”身份。
- 角色管理为唯一授权入口：创建、编辑角色，勾选可访问知识库；知识库侧只读查看授权角色。
- 新增或调整员工必须明确选择至少一个有效角色，没有自动分配的通用角色。
- 员工可有多个角色，可访问知识库取并集；角色也可不授权任何库。
- 内置系统管理员使用稳定标识 system_admin，拥有系统管理及全部知识库访问能力，不能编辑、删除或缩减。
- 自定义角色仅授予文档读取和问答。用户、角色、知识库、文件写入与系统设置仍限系统管理员。
- 不能移除最后一名管理员；已分配用户的角色不能删除。系统管理员不能查看他人的会话。

## 数据与接口

- roles、user_roles、role_knowledge_bases 分别保存角色、员工角色和角色知识库关系；关联使用复合主键、外键及查询索引。
- 彻底删除 users.role；授权不依赖旧枚举或角色显示名称。
- 登录、当前用户、用户列表只返回 id、username、roles、is_admin；保留 JWT 密码版本校验。
- GET/POST /api/roles、PUT/DELETE /api/roles/{id} 管理角色。
- POST /api/users 必填 role_ids；PUT /api/users/{id}/roles 调整角色，旧 role 字段拒绝。
- GET /api/knowledge-bases/{kb_id}/roles 为管理员只读展示授权。
- 名称、长度、正整数资源 ID、未知关联与唯一约束都要校验。授权写入与审计同一事务提交。
- 所有授权变更先锁 system_admin 角色行，再锁目标用户。最后管理员计数及变更在同一事务，防止并发越过保护。

## 授权链路

集中权限服务覆盖知识库列表/统计、文件列表、完整分块与单块详情、引用、会话创建/列表/历史/继续，以及首页数据。
未授权资源返回 404；非管理员调用管理接口返回 403。无角色的原员工默认不能读取任何库，管理员必须明确分配。

向量检索与 BM25 都在 SQL 查询阶段根据当前认证 user_id 过滤。缺少用户或有效知识库的内部检索直接拒绝，异常降级不扩大授权范围。

## 上下文和在途撤权

- conversation.memory_epoch 为授权上下文版本；员工角色或角色知识库清单变更时递增并清空已完成上下文指针。
- 每次生成使用 rbac-v1-user-用户-conv-会话-epoch-版本-随机ID 独立线程。只从已原子提交到 memory_thread_id 的线程延续上下文；失败、撤权或中断任务永不复用。
- 旧 Checkpoint 不加载，也不从旧 Message 或摘要回灌；本次初始化清理全部旧消息和会话。
- 在途流每秒用短事务复核，即使模型静默也会取消。监控持续到生成与客户端消费都结束，不能在模型完成后放任积压队列继续发送。
- 撤权时取消并等待生成结束，丢弃排队内容，返回 permission_revoked 错误。已发送内容不能撤回。
- 最终授权、epoch 检查和 assistant 消息/上下文指针写入在同一事务，用授权共享锁与变更排他锁同步；发送来源前再次复核。
- 等待模型期间不占用请求数据库连接。前端权限失败后刷新身份与可读库，保留错误提示并清除失效选择。
- 已有新系统会话在撤权后隐藏，重新授权后可看历史；模型记忆因 epoch 更新重新开始。

## 本地初始化与保留数据

用户已明确：系统尚未使用，本次按新系统迭代，不处理旧数据兼容；只保留原有知识库内容。

1. 关闭旧后端，预检并备份数据库和上传文件。独立命令 --plan 只读，--apply 显式执行事务初始化。
2. 创建角色表、关联与版本标记，使用数据库事务锁防止重复/并发初始化。
3. 识别原管理员并关联系统管理员，不改密码；其他原账号仅保留用户行供文件创建者等外键引用，不授予共享访问。
4. 删除旧 users.role 字段；清理旧 messages 和 conversations，避免废弃会话阻塞知识库删除。未知外键依赖会阻止并回滚。
5. 不改变 knowledge_bases、files、chunks（含 embedding）或原始上传文件；初始化前后用行指纹与文件哈希核对。
6. 正常启动检查标记，不自动给旧用户补授权。空数据库安装直接创建管理员、权限标记及默认知识库。
7. 重复应用不重新授权、不清理新会话。回退需要配套恢复初始化前完整备份，不能直接启动旧代码。

详细操作见 [角色权限迁移](../../角色权限迁移.md)。不增加依赖、不改密钥或生产配置，不自动提交推送。
