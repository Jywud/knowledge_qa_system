# 默认跨授权知识库问答计划

用户已确认：默认查询全部可访问知识库，左下角可选限定单库；允许备份后更新本地会话结构。沿用现有主题及输入区布局，不新增依赖，不提交推送。

## 设计

- kb_id 为空表示全部授权范围，不代表任意库。创建时记录当前可读知识库 ID 集合，单库选择记录该库。
- 会话范围固定。角色新增知识库后新建会话才能纳入；撤回任一范围内库权限时，隐藏该会话历史、停止在途任务且不复用旧记忆。删除自己的会话仍可执行。
- 新增 conversations.kb_scope TEXT 保存范围 JSON，提供显式只读预检和事务迁移；普通启动不偷偷迁移。
- 检索同时使用当前认证权限与会话范围，向量、BM25 及异常降级均不得扩大。引用显示知识库名、文档和版本；提示模型区分冲突。
- 默认下拉项“全部可访问知识库”；存在可用授权内容即可直接发送。无权限/无文档时给明确提示；已创建会话不能切换范围。
