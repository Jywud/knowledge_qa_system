## 验证命令

从 backend 运行：`.venv/Scripts/python.exe -B -m pytest tests -q`。
显式 PostgreSQL 隔离测试：设置 `RBAC_POSTGRES_TESTS=1` 后运行 `tests/test_roles_postgres.py`；仅创建并清理随机测试 schema。
从 frontend 运行：`node --test tests/*.spec.js`、`npm run build`。

最终验证：启用 PostgreSQL 隔离测试后，后端全量 156 通过、2 项原可选检索用例跳过；前端 60 通过、构建通过；编译、差异格式和文档链接检查通过。真实浏览器与原知识库数据核验完成，详见[验收记录](../../角色权限验收记录.md)。
