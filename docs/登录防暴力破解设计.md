# 登录防暴力破解设计

## 目标

防止攻击者通过反复尝试密码猜测用户凭据。

## 方案

在登录接口增加内存计数器（不依赖额外表或 Redis）：

- 同一用户名连续登录失败 5 次后，锁定该用户名 15 分钟。
- 锁定期间返回 HTTP 429 与中文提示。
- 登录成功后重置该用户名的计数。
- 计数器记录：失败次数、首次失败时间、锁定截止时间。

## 局限

单实例内存计数器，多实例部署时各实例独立计数。当前项目为单实例部署，满足需求；后续横向扩展时可替换为 Redis 或数据库表。

## 配置

通过环境变量控制（写入 `backend/.env`）：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `LOGIN_MAX_ATTEMPTS` | `5` | 最大连续失败次数 |
| `LOGIN_LOCK_MINUTES` | `15` | 锁定时长（分钟） |
