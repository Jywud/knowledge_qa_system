# 需求文档（PRD）

版本：v1.1（2026-10-27）　状态说明：✅ 已实现　🚧 规划中

## 1. 产品定位

企业内部知识库问答系统：管理员维护知识库文件，全员基于知识库进行多轮智能问答，回答可溯源。

## 2. 用户与角色

| 角色 | 能力 |
|---|---|
| 普通用户 | 对话问答、查看全部知识库文件及其分块、管理自己的会话 |
| 管理员 | 普通用户全部能力 + 上传 / 更新 / 删除知识库文件 |

- 账号密码登录（✅）：独立登录页 `/login`，JWT 有效期 24 小时
- 默认管理员：`admin / 123456`（首次启动自动创建，请尽快修改密码）
- 其他用户由管理员在「用户管理」页新增，支持设置角色（普通用户 / 管理员）

## 3. 功能需求

### 3.1 知识库文件管理（✅）

- 支持上传 `md` / `txt` / `docx` / `pdf` 文件，其他类型拒绝
- 文件全员共享可见，列表展示：文件名、类型、大小、版本、状态、分块数、上传者、上传时间
- 管理员可一次选择并上传最多 10 个文件；每个文件独立解析、分块和向量化
- 上传接口快速返回，向量化在后台执行；状态流转为：处理中 / 就绪 / 失败
- 仅管理员可上传、更新、删除
- 更新文件：新内容覆盖旧内容，版本号 +1，旧分块全部清除后重新切分入库
- 删除文件：同时删除其全部分块与向量数据
- 可查看每个文件的分块内容（序号、页码、内容）

### 3.2 对话问答（✅）

- 输入问题即可直接对话，首条消息自动创建会话
- 回答基于知识库检索结果生成，流式输出
- 回答仅在真实引用知识块时输出来源编号；前端按文件聚合展示引用，点击可查看摘录
- 多轮对话：支持上下文追问
- 发送给大模型的最近历史消息默认限制为 20 条，避免长会话超窗
- 会话按用户隔离，互不可见
- 对话记录列表：新建、点击切换续聊、删除
- 刷新浏览器自动恢复最近会话

### 3.3 登录与用户管理（✅）

- 独立登录页：账号 + 密码表单，回车可提交，登录成功后进入对话页
- 所有业务接口要求 JWT，401 时自动清除凭证并跳转登录页
- 登录用户可在右上角菜单修改自己的密码：需要验证原密码，新密码至少 6 位且不能与原密码相同
- 用户管理页（仅管理员可见入口）：
  - 用户列表：ID、用户名、角色
  - 新增用户：用户名 + 密码（至少 6 位）+ 角色
  - 重置密码：为指定用户设置新密码
  - 删除用户：不能删除自己

### 3.4 规划中（🚧）

- 检索优化：rerank 重排、parent-child 分块检索、多轮查询改写
- 多智能体路由（闲聊 / 检索 / 表格查询）
- 问答质量评估集
- PostgreSQL 全文检索替代 Python 内存 BM25

### 3.5 检索优化与来源元数据（✅）

- 问答采用混合检索：向量检索 + BM25 关键词检索
- 两种检索结果通过 RRF 融合，最终按系统设置的 TopK 返回知识块
- pgvector 使用 HNSW 余弦相似度索引；向量相似度阈值默认 `0.5`，可通过 `backend/.env` 配置
- 向量服务异常时自动降级为 BM25；向量结果为空时不使用关键词兜底，模型如实回答知识库中没有相关内容
- 精确关键词、编号、型号、专有名词更容易被召回
- 来源元数据补充文件类型、知识库名称、页码
- 不新增运行时依赖；BM25 使用后端内存中的轻量实现

## 4. 验收要点

1. 普通用户看不到上传/删除按钮，接口层也被拒绝（403）
2. 删除文件后提问不再命中该文件内容
3. 删除会话后其记忆（checkpoint）同步清除，重新提问视为全新上下文
4. 刷新页面不丢失会话列表与当前对话内容
5. 未登录访问任何页面跳转登录页；token 过期后自动清除凭证并跳转登录页
6. 普通用户登录后看不到「用户管理」入口，直接访问 `/users` 页面时接口返回 403
