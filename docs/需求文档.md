# 需求文档（PRD）

版本：v1.3（2026-11-12）　状态说明：✅ 已实现　🚧 规划中

## 1. 产品定位

企业内部知识库问答系统：管理员维护知识库文件，员工在角色授权范围内进行跨知识库多轮智能问答，回答可溯源。

## 2. 用户与角色

| 角色 | 能力 |
|---|---|
| 业务角色 | 读取授权知识库的文件和分块、对话问答、管理自己的会话 |
| 系统管理员（内置角色） | 管理用户、角色、全部知识库与文件及系统设置 |

- 账号密码登录（✅）：独立登录页 `/login`，JWT 有效期 24 小时
- 默认管理员：`admin / 123456`（首次启动自动创建，请尽快修改密码）
- 其他用户由管理员在「用户管理」页新增，必须明确选择至少一个角色，多个角色的知识库权限取并集；无固定普通用户角色

## 3. 功能需求

### 3.1 知识库文件管理（✅）

- 支持上传 `md` / `txt` / `docx` / `pdf` 文件，其他类型拒绝
- 文件仅在当前角色授权范围内可见，列表展示：文件名、类型、大小、版本、状态、分块数、上传者、上传时间
- 管理员可一次选择并上传最多 10 个文件；每个文件独立解析、分块和向量化
- 上传接口快速返回，向量化在后台执行；状态流转为：处理中 / 就绪 / 失败
- 仅管理员可上传、更新、删除
- 单文件默认上限 50MB，超限返回 413
- 更新文件：先后台处理新内容，成功后事务切换分块并将版本号 +1；失败保留原文件、分块和版本
- 删除文件：同时删除其全部分块与向量数据
- 可查看每个文件的分块内容（序号、页码、内容）

### 3.2 对话问答（✅）

- 默认直接查询全部可访问知识库，也可在输入区左下角限定单库；首条消息创建会话并记录范围快照，之后不可切换范围
- 回答基于知识库检索结果生成，流式输出
- 回答按来源编号渲染数字角标；按文件 ID/版本聚合引用，引用显示知识库名，弹窗按块加载原文。文件更新/删除显示失效，旧格式仅展示保存摘要
- 范围内任一库失去授权时隐藏该会话历史并停止在途回答；无可用分块时拒绝提问；流中断提示并保留已收到内容。旧无有效范围会话不开放
- 多轮对话：支持上下文追问
- 发送给大模型的最近历史消息默认限制为 20 条，避免长会话超窗
- 会话按用户隔离，互不可见
- 对话记录列表：新建、点击切换续聊、删除
- 刷新浏览器自动恢复最近会话

### 3.3 登录与用户管理（✅）

- 独立登录页：账号 + 密码表单，回车可提交，登录成功后进入首页工作台
- 所有业务接口要求 JWT，401 时自动清除凭证并跳转登录页
- 登录用户可在右上角菜单修改密码：验证原密码，新密码 6～128 位、非全空白且不能与原密码相同；修改或管理员重置后旧令牌失效
- 登录响应和前端用户缓存不含密码哈希；按客户端来源限流，可信代理防止外部伪造来源头，见专项设计
- 用户管理页（仅管理员可见入口）：
  - 用户列表：ID、用户名、角色
  - 新增用户：用户名去首尾空白后为 1～64 字符，密码使用统一新密码规则，必选一个或多个有效角色
  - 重置密码：为指定用户设置新密码
  - 删除用户：不能删除自己，有关联知识库/上传文件/会话/审计数据时返回 409

### 3.4 规划中（🚧）

- 检索优化：rerank 重排、parent-child 分块检索、多轮查询改写
- 多智能体路由（闲聊 / 检索 / 表格查询）
- 问答质量评估集
- PostgreSQL 全文检索替代 Python 内存 BM25
- 部门继承或文档级权限、持久化入库任务、完整历史版本留存与回滚

### 3.5 检索优化与来源元数据（✅）

- 问答采用混合检索：向量检索 + BM25 关键词检索
- 两种检索结果通过 RRF 融合，最终按系统设置的 TopK 返回知识块
- pgvector 使用 HNSW 余弦相似度索引；向量相似度阈值默认 `0.5`，可通过 `backend/.env` 配置
- 向量服务异常时自动降级为 BM25；向量结果为空时不使用关键词兜底，模型如实回答知识库中没有相关内容
- 精确关键词、编号、型号、专有名词更容易被召回
- 来源元数据补充文件类型、知识库名称、页码
- BM25 使用 LangChain Community 的 `BM25Retriever`，在后端内存中构建；尚未接入 PostgreSQL 全文检索

## 4. 验收要点

1. 业务角色看不到上传/更新/删除按钮，接口层也被拒绝（403）
2. 删除文件后提问不再命中该文件内容
3. 删除会话后其记忆（checkpoint）同步清除，重新提问视为全新上下文
4. 刷新页面不丢失会话列表与当前对话内容
5. 未登录访问任何页面跳转登录页；token 过期后自动清除凭证并跳转登录页
6. 业务角色看不到用户/角色/系统设置管理入口，管理API返回403；管理页面路由会跳回问答

### 角色与授权验收（✅）

- 管理员在角色页勾选知识库；知识库侧只读查看授权角色。
- 内置系统管理员角色不可改删，不允许移除最后一名管理员；使用中的角色不可删除。
- 向量、BM25和异常降级都必须过滤当前角色权限与会话范围；猜文件/分块ID也无法越权。
- 新增授权不扩大旧会话范围，撤权后旧摘要和未完成Checkpoint不复用。
- 具体初始化及保留数据边界见[角色权限迁移](角色权限迁移.md)与[跨库问答说明](跨库问答说明.md)。
