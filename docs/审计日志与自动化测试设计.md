# 审计日志与自动化测试设计

## 审计日志

### 目标

记录敏感操作，便于追溯问题。

### 方案

新增 `audit_logs` 表，记录：操作人、操作类型、目标对象、详情、时间。通过 `log_audit()` 辅助函数在敏感路由中插入记录。

### 记录范围

| 操作类型 | 路由 | 触发时机 |
|---------|------|---------|
| user.create | POST /api/users | 创建用户成功 |
| user.delete | DELETE /api/users/{id} | 删除用户成功 |
| user.reset_password | PUT /api/users/{id}/password | 重置密码成功 |
| file.upload | POST /api/files | 上传文件成功 |
| file.delete | DELETE /api/files/{id} | 删除文件成功 |
| kb.create | POST /api/knowledge-bases | 创建知识库成功 |
| kb.delete | DELETE /api/knowledge-bases/{id} | 删除知识库成功 |

## 自动化测试

### 目标

覆盖核心链路：登录认证、用户管理、知识库文件上传、问答。

### 方案

默认测试使用 SQLite 内存库（aiosqlite）并启用外键约束，上传写入临时目录。Embedding、LLM 和 Graph 在测试中模拟；两项真实检索回归默认跳过。使用 pytest + pytest-asyncio + httpx.AsyncClient，前端使用 Node 内置测试器。

覆盖登录字段白名单、密码版本撤销、来源限流与代理防伪造、删除冲突、文件更新失败回滚、会话绑定校验、模型等待时请求事务释放、启动补向量失败隔离、来源元数据与按块加载。前端覆盖 HTTP/SSE 错误恢复、旧引用兼容、缓存清理及 Markdown 转换。

### 运行命令

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install pytest pytest-asyncio httpx aiosqlite
.\.venv\Scripts\python.exe -B -m pytest tests -q -p no:cacheprovider
```

```powershell
cd frontend
node --test tests/*.spec.js
npm run build
```

真实检索回归：准备 PostgreSQL、Embedding 服务和 `tests/test_retrieval_regression.py` 中指定的知识库/样例文件，按实际环境调整 ID 与预期来源；在 `backend/` 设置 `$env:RUN_RETRIEVAL_TESTS='1'`，运行 `.\.venv\Scripts\python.exe -m pytest tests/test_retrieval_regression.py -q`。这会调用真实 Embedding 服务，默认回归不会执行。
